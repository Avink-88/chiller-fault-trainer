# 冰水主機故障檢修模擬

冷凍空調裝修 **乙級・第三站** 練習用的網頁互動遊戲。給碰不到實體設備、或第一次接觸的同學，在瀏覽器裡練習故障檢修。

**▶ 直接玩：** https://avink-88.github.io/chiller-fault-trainer/

## 功能

- **互動控制電路圖**：X 自保持、冰水泵、冷卻水泵、水塔風扇、安全連鎖（FS、HP、LP、THC、TC）、Y-Δ 啟動、SV、曲軸箱加熱器
- **三用電表**：ACV／Ω 檔，點端點放紅黑棒；讀值由電路實際計算
- **隨機出題**：1～3 處故障（線圈斷路、接點不通、保險絲熔斷、指示燈燒毀、導線斷線）
- **連鎖現象**：例如風扇故障 → 高壓上升 → HP 跳脫，要找出根本原因
- **現場設備動畫**：冷卻水塔、水泵、壓縮機、壓力錶、水溫
- **計分與紀錄**：分數、用時、量測紀錄表、判定紀錄

## 怎麼用

- **學生**：打開上面的網址即可，手機、平板、電腦都能玩
- **離線**：下載 `index.html`，用瀏覽器打開（第一次需要網路載入字型）

# 冰水主機故障檢修模擬

冷凍空調裝修 **乙級・第三站** 練習用的網頁互動遊戲。給碰不到實體設備、或第一次接觸的同學，在瀏覽器裡練習故障檢修。

**▶ 直接玩：** https://avink-88.github.io/chiller-fault-trainer/

## 功能

- **依檢定接線圖繪製**：控制電路與主電路分開兩張圖，線號與原圖相同
- **主電源／控制電源分開**：NFB1（3φ 主電路、47R）與 NFB2（控制電路、D-FUSE、E-STOP）
- **完整保護迴路**：F.S1、F.S2、EW、油位、26W、47R、51C、63HR、63LP、23C4、49C，各有異常指示燈
- **Y-Δ 起動與容量控制**：2G1 再起動延時 → 6S → 52C → 2S → 42D；2C1、2C2 依序切換 CSV-1～3
- **三用電表**：ACV／Ω 檔，三相電壓以相量計算；控制電路與主電路的端點可以互量
- **隨機出題**：1～3 處故障，可選擇是否包含導線斷線與主電路
- **連鎖現象**：例如 SV2 不動作 → 吐出溫度升高 → 49C 停機，要找出根本原因
- **操作導覽與下一步引導**：第一次打開自動導覽；盤面依狀態提示下一步
- **我的記事本**：邊量邊記，一鍵插入讀值與元件狀態
- **現場設備動畫**：冷卻水塔、水泵、壓縮機、壓力錶、水溫
- **計分與紀錄**：分數、用時、量測紀錄表、判定紀錄

## 怎麼用

- **學生**：打開上面的網址即可，手機、平板、電腦都能玩
- **離線**：下載 `index.html`，用瀏覽器打開（第一次需要網路載入字型）

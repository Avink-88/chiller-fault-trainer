# 03｜常見修改教學

每次修改的流程都一樣：

1. 用 VS Code 打開 `index.html`
2. **Ctrl + F** 搜尋關鍵字，找到要改的地方
3. 改數字或文字，**Ctrl + S** 存檔
4. 用瀏覽器打開 `index.html`（或按 F5 重新整理），確認結果
5. 改壞了也不用怕，可以用 Git 還原（見 [04-Git與GitHub入門](04-Git與GitHub入門.md)）

> 改的時候只動「數字」和「引號裡的中文字」，符號 `{ } ( ) , ; ' "` 不要刪掉，最容易出錯的就是少一個逗號或引號。

---

## 範例 1：改扣分（最簡單）

搜尋 `【計分】`，會找到這行：

```js
E.score=Math.max(0,E.score-10);
```

把 `-10` 改成 `-5`，答錯就只扣 5 分。`Math.max(0, …)` 的意思是「最低 0 分，不會變負的」。

## 範例 2：改 Y-Δ 切換時間

搜尋 `TR 限時電驛`：

```js
if(P&&en.TR){ S.trTime+=dt; if(S.trTime>=4) S.trDone=true; }
```

把 `4` 改成 `6`，TR 就會在 6 秒後切換。記得也把畫面說明裡的「4 秒」一起改掉（搜尋「4 秒」）。

## 範例 3：改高壓跳脫設定

搜尋 `S.HP>=20`，把 `20` 改成你要的數值（kg/cm²）。
同一區還有低壓設定 `S.LP<=1.5`（開路）和 `S.LP>=3`（復歸）。

## 範例 4：改畫面文字

想改右下角「練習步驟」的內容？直接搜尋畫面上看到的那句中文，改掉就好。
例如搜尋 `送電觀察`，就能找到第一步的文字。

## 範例 5：讓某個元件不會被出成故障

搜尋 `const EXCLUDE`：

```js
const EXCLUDE=new Set(['THCal','YL']);
```

把元件的 id 加進去，例如不想考保險絲：

```js
const EXCLUDE=new Set(['THCal','YL','F']);
```

元件 id 在【電路定義】裡每個元件的 `id:'…'`。

## 範例 6：改顏色

搜尋 `【顏色設定】`，例如：

```css
--accent:#0d6870;
```

`--accent` 是主要強調色（按鈕、標記）。換成 `#1d4ed8` 就變藍色。
深色模式的顏色在下面另一組，要一起改。

---

## 想做更大的修改？

例如「換成實際檢定電路圖」「加一種新故障」，直接把需求告訴 Claude 就好。
你可以先描述想要的效果，等它改完再對照這份筆記，看它動了哪些地方，這樣學得最快。

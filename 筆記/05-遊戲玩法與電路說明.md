# 05｜遊戲玩法與電路說明（可以直接給學生看）

## 基本操作

| 動作 | 怎麼做 |
|---|---|
| 送電／斷電 | 點控制盤面左邊的 **NFB** 開關 |
| 按 ON／OFF | **送電時**：按住才算按下。**斷電時**：點一下＝持續壓住（方便量電阻），再點一下放開 |
| 手動壓接觸器 | 斷電時點「盤內元件」的方塊（例如 MCP），就能用 Ω 檔量它的接點 |
| 量測 | 先選檔位（ACV 或 Ω），再點電路圖上的**黑色小圓點**放探棒，紅棒、黑棒會輪流放 |
| 判定故障 | 切到「判定故障」模式，點元件或導線，選擇故障情形 |
| 加速 | 「時間 ×3」可以讓水溫、壓力變化快一點 |

## 計分

- 起始 100 分，60 分及格
- 判定錯誤（位置錯）：−10
- 位置對、故障情形錯：−5
- 使用提示：每處故障 −5
- 帶電使用電阻檔：−5

## 電路動作順序（正常時）

1. NFB 送電 → **GL** 停止燈亮、**CH** 曲軸箱加熱器通電
2. 按 **ON** → **X** 吸合並自保持（X-a 自保持接點）→ GL 熄滅
3. X-a 閉合 → **MCP**（冰水泵）、**MCT**（冷卻水泵）、**MCF**（水塔風扇）吸合，RL1～RL3 亮
4. 水流建立 → **FS1**、**FS2** 閉合
5. 安全連鎖全通（X-a、MCP-a、FS1、MCT-a、FS2、HP、LP、THC、TC）→ **K 點**有電
6. K 點有電 → **MCM**、**SV**、**RL4**、**TR**、**MCS** 通電 → 壓縮機 **Y 接線啟動**，CH 斷電
7. TR 計時 4 秒 → TR-b 打開（MCS 釋放）、TR-a 閉合（MCD 吸合）→ **Δ 運轉**
8. 冰水降到 7 °C → **TC** 開路，壓縮機停機；回升到 10 °C 再啟動

## 會出的故障類型

| 類型 | 例子 | 常見現象 |
|---|---|---|
| 保險絲熔斷 | F | 全部不動作、所有燈不亮 |
| 按鈕接點不通 | PB-ON、PB-OFF | 按 ON 沒反應 |
| 自保持接點不通 | X-a（第 1 行下方） | 按住 ON 才會動，放開就停 |
| 線圈斷路 | MCP、MCF、TR、MCS… | 該吸合的接觸器沒吸合 |
| 接點不通 | MCP-a、FS1、HP、TC… | 前面都正常，壓縮機就是不啟動 |
| 指示燈燒毀 | RL1、GL… | 設備有運轉但燈不亮 |
| 導線斷線 | 任何一段線 | 和接點不通類似，要量到斷點才知道 |

## 連鎖現象（考驗推理）

這些故障的**現象出現在別的地方**，要找出根本原因，不要選成跳脫的那個開關：

| 根本故障 | 你會看到 |
|---|---|
| MCF 線圈斷路（風扇不轉） | 壓縮機運轉後高壓一直升 → **HP 跳脫** |
| SV 線圈斷路（電磁閥不開） | 壓縮機啟動後低壓掉很快 → **LP 開路**，反覆啟停 |
| TR 線圈斷路（不會切 Δ） | 一直停在 Y 運轉 → 25 秒後 **THC 過載跳脫** |
| MCD 線圈斷路 | Y 啟動 4 秒後壓縮機停住，RL4 卻還亮著 |

## 量測技巧

- **帶電找斷點**：ACV 檔，黑棒放 **N 母線**，紅棒沿著線路從左往右點。哪裡 220 V 變 0 V，斷點就在那一段。
- **量開路的接點兩端**：讀到 220 V（因為後面的線圈把 N 電位帶過來了）。
- **斷電量元件**：NFB 打 OFF，切 Ω 檔
  - 線圈：數百 Ω～數 kΩ（MC 約 300～400 Ω、X 約 1.2 kΩ、TR 約 4 kΩ）
  - 閉合的接點：約 0 Ω
  - 開路：顯示 **OL**
- 量 a 接點時，可以手動壓下接觸器，確認接點會不會導通。

> 這是教學用的代表性電路，元件編號與實際檢定圖可能不同。

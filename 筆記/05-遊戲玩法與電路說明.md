# 05｜遊戲玩法與電路說明（可以直接給學生看）

## 兩種練習模式

| 模式 | 用途 |
|---|---|
| **正常運轉觀摩** | 沒有任何故障、不計時、不計分。會自動打開「顯示通電狀態」和「正常動作順序」，適合第一次接觸的同學先看懂正常時每個元件怎麼動作，也可以先量一次正常時的電壓、電阻記在記事本，之後找故障時拿來比較 |
| **故障檢修** | 隨機故障、計時、計分，模擬檢定 |

畫面底部控制列有固定的「**觀摩｜考試**」切換，隨時可以換：
- 考試進行中按「觀摩」：先跳出「放棄本次考試？」，可選「繼續考試」或「放棄並切換到觀摩」（考試進度不保留）。
- 觀摩中按「考試」：回到開始畫面，選好故障數量與時間限制後開始。

建議教學順序：先用「正常運轉觀摩」跟著動作順序走一遍 → 再用「故障檢修」1 處故障、不限時 → 最後 3 處故障、60 分鐘。

## 現場設備

現場圖裡運轉中的設備會變成綠色，壓縮機運轉時會輕微震動，水流和冷媒流動的動畫也加粗了。
圖下方的**狀態卡**直接寫出冰水泵、冷卻水泵、壓縮機、容量、冰水溫度、SV2、CCH、電流。
按「**放大檢視**」可以把現場圖放大到畫面中央（按「關閉」或 Esc 回去）。

## 開始畫面

打開遊戲會先看到**開始畫面**：選好故障數量、是否包含導線斷線、主電路故障、時間電驛設定錯誤，以及**時間限制**（預設 60 分鐘，同檢定；也可選 30 分鐘或不限時），按「開始練習」才開始計時。

時間到會暫停並跳出「**時間到，本次未通過**」，可以選「繼續練習」把剩下的找完（仍記為未通過），或「重新開始」。剩下 5 分鐘時，控制列的時間會變紅色。
第一次玩可以先按「先看操作導覽」，之後也能按右上角的「操作導覽」重看。按「出新題」會回到開始畫面。

畫面底部固定有**控制列**，捲動到哪裡都看得到：

| 按鈕 | 作用 |
|---|---|
| 開始 | 沒有進行中的題目時，打開開始畫面 |
| 暫停／繼續 | 暫停時計時、延時電驛、溫度與壓力全部停住，畫面會蓋上遮罩；再按一次「繼續」 |
| 停止 | 結束本題，並在電路圖上標出所有故障位置 |
控制盤面上方的「下一步」會依目前狀態提示該做什麼，熟練後可以取消勾選「顯示操作引導」。

## 基本操作

| 動作 | 怎麼做 |
|---|---|
| 主電源 | **NFB1**（3φ 220 V，供壓縮機與 47R） |
| 控制電源 | **NFB2**（R、T 兩相 220 V，經 D-FUSE、E-STOP 供控制電路） |
| 緊急停止 | 紅色 **E-STOP**，點一下壓下、再點一下解除 |
| 外部設備 | **冰水泵**、**冷卻水泵**開關；開了才有水流，F.S1、F.S2、EW 才會閉合 |
| 選擇開關 SW | 近控／停止／遠控；遠控時由「遠控接點 F」起動 |
| 起動／停止 PB | **送電時**：按住才算按下。**斷電時**：點一下＝持續壓住（量電阻用） |
| 手動壓電驛 | NFB2 斷電時點「盤內元件」的電驛（例如 52C），就能用 Ω 檔量它的接點 |
| 量測 | 選檔位（ACV 或 Ω），點電路圖上的**黑色小圓點**放探棒；「控制電路」「主電路」兩張圖可以互量 |
| 縮放電路圖 | 工具列的 －／＋ |
| 判定故障 | 切到「判定故障」，點元件或導線，選擇故障情形 |
| 記事本 | 可以打字，或按「插入目前讀值／時間／元件狀態」自動記錄 |
| 加速 | 「時間 ×3」讓計時、水溫、壓力變化快一點 |

## 計分

- 起始 100 分，60 分及格，而且要在時間限制內完成
- 判定錯誤（位置錯）：−10
- 位置對、故障情形錯：−5
- 使用提示：每處故障 −5
- 帶電使用電阻檔：−5（量控制電路要關 NFB2，量主電路要關 NFB1）

## 正常動作順序

1. **NFB1** 送電 → 47R 檢出三相正常
2. **NFB2** 送電 → **WL** 電源燈亮、**CCH** 曲軸箱加熱器通電（52C b 接點）
3. 啟動冰水泵、冷卻水泵 → **F.S1**、**F.S2** 閉合；**EW** 有壓差 → **2G5** 通電、**YL6** 熄滅
4. SW 切「近控」→ **10 號線**有電 → **LO**（油位正常）→ **2G3** → **X4** → **2G4** 計時（計時中 YL1 會短暫亮）
5. 按起動 PB → 保護控制迴路 **9 → 22** 全通（26W、PB 停止、47R、X2、51C、63HR、63LP、2G4、2G5、23C4、49C）→ **X1** 吸合自保持
6. **23C1 OUT2** 在需冷卻側（冰水 ≥ 10 °C，接 33 號線）＋ X1 → **2G1** 再起動延時計時；同時 **CSV-1（25%）** 通電
7. 2G1 到 → **6S**（Y）吸合 → 6S a 接點使 **52C** 吸合並自保持 → 壓縮機 **Y 起動**，**GL1** 亮、**SV1** 回油電磁閥開、CCH 斷電
8. **2S** 計時到 → 2S b 打開（6S 釋放）、2S a 閉合 → **42D** 吸合 → **Δ 運轉**，**2C1** 開始計時
9. 2C1 到 → CSV-1 斷電、**2C2** 開始計時；2C2 到 → **CSV-2（50%）** 通電，23C1 **OUT1** 閉合時 **CSV-3（75%）** 也通電。CSV 通電＝加載，現場圖會顯示目前容量，容量越大冰水降溫越快
10. 吐出溫度 ≥ 95 °C → **23C3** 閉合 → **2G2** 以 ON 5 秒／OFF 10 秒控制 **SV2** 旁通降溫
11. 冰水降到 7 °C → 23C1 OUT2 切到 **31 號線** → **GL2** 亮、壓縮機停機；回升到 10 °C 再起動

> 延時電驛的時間已縮短方便練習，例如 2G1 檢定圖是 6 min，遊戲裡是 12 秒。盤內元件方塊會顯示倒數。

## 會出的故障類型

| 類型 | 例子 | 常見現象 |
|---|---|---|
| 控制電源 | NFB2 某一極、D-FUSE、E-STOP | WL 不亮、全部不動作 |
| 主電源缺相 | NFB1 某一極 | 47R 異常 → **RL1** 亮、X2 保持，保護迴路不通 |
| 流量／壓差 | F.S1、F.S2、EW、2G5 | 泵有開但 X1 無法起動 |
| 油位保護 | LO、2G3、X4、2G4 | **YL1** 一直亮、X1 無法起動 |
| 保護迴路接點 | 26W、47R、X2、51C、2G4、2G5、49C | 按起動 X1 不吸合 |
| 自保持接點 | X1（21–22 下方） | 按住起動才動，放開就停 |
| 溫控 | 23C1 OUT2 | 需冷卻卻不起動，或 GL2 不亮 |
| 容量控制 | 2C1、2C2、CSV-1～3、OUT1 | 壓縮機正常運轉，但現場圖的 CSV 指示不照順序動作 |
| Y-Δ | 6S、52C、2S、42D 線圈或接點 | 無法起動、卡在 Y、切 Δ 後停 |
| 主電路 | MCM、MCS、MCD 某一極 | 壓縮機嗡嗡聲 → 51C 跳脫 → **YL4** |
| 指示燈／加熱器 | WL、GL1、GL2、CCH | 設備正常但燈不亮、加熱器不熱 |
| 導線斷線 | 任何一段有線號的線 | 和接點不通類似，要量到斷點才知道 |
| **時間電驛設定錯誤** | 2S、2G1、2G2、2G4、2C1、2C2 | 電路量起來都正常，但動作時間不對。對照盤內元件的倒數和正確設定值；判定時點該時間電驛的**線圈**，選「時間設定錯誤」 |

## 連鎖現象（考驗推理）

| 根本故障 | 你會看到 |
|---|---|
| SV2、2G2 或 23C3 故障 | 運轉一段時間後吐出溫度一直升 → **49C 動作停機**，沒有異常燈 |
| 2S 線圈斷路 | 一直停在 Y 運轉 → 25 秒後 **51C 跳脫**、YL4 亮 |
| 42D 線圈斷路 | Y 起動後 52C 還吸著，但壓縮機停住 |
| 6S 線圈斷路 | 2G1 計時到了，52C 卻不會吸合（52C 要靠 6S a 接點） |
| MCM 某一極不通 | Y 起動時嗡嗡聲 → 51C 跳脫 |
| 2S 時間設太長 | 一直停在 Y 運轉 → 51C 跳脫（和 2S 線圈斷路很像，差別在 2S 有在計時） |
| 2G2 時間設定錯誤 | SV2 旁通時間太短 → 吐出溫度升高 → 49C 停機 |
| 2C1／2C2 時間設太長 | 容量一直停在 25% 或 0%，冰水降溫很慢 |
| NFB1 某一極不通 | RL1 亮；修好後還要按**停止 PB** 才能解除 X2 保持 |

## 量測技巧

- **帶電找斷點**：ACV 檔，黑棒放 **N 母線（2 號線）**，紅棒沿線號由小到大逐點量。哪裡 220 V 變 0 V，斷點就在那一段。
- **量開路的接點兩端**：讀到 220 V（因為後面的線圈把 2 號線的電位帶過來了）。
- **主電路**：R1–S1、S1–T1、R1–T1 都應該是 220 V；量 MCM 二次側 1、2、3 號端子可以判斷哪一相沒過來。
- **斷電量元件**：先關對應的 NFB，切 Ω 檔
  - 線圈：數百 Ω～數 kΩ（52C 約 300 Ω、6S／42D 約 340 Ω、X 電驛約 1.2 kΩ、延時電驛約 4 kΩ）
  - 壓縮機繞組 1-4、2-5、3-6：約 0.6 Ω
  - 閉合的接點：約 0 Ω；開路：顯示 **OL**
- 量 a 接點時，可以手動壓下電驛，確認接點會不會導通。

# 01｜網頁是什麼？用這個遊戲來認識

## 一句話版本

網頁就是一個 **文字檔**（副檔名 `.html`），瀏覽器（Chrome、Edge）讀了它之後，把內容畫成你看到的畫面。
這個遊戲只有一個檔案：`index.html`。用記事本打開會看到一堆文字，用瀏覽器打開就是遊戲。

## 三種語言，三種工作

| 語言 | 負責什麼 | 比喻成冰水主機 | 在 index.html 的哪裡 |
|---|---|---|---|
| **HTML** | 畫面上**有什麼**：標題、按鈕、表格 | 配電盤上**裝了哪些元件** | `<body>` 裡面的 `<標籤>` |
| **CSS** | 東西**長什麼樣**：顏色、大小、位置 | 元件的**外殼顏色、銘牌** | `<style>` … `</style>` |
| **JavaScript** | 東西**怎麼動**：按下去會發生什麼 | **控制電路**：按 ON 之後誰吸合 | `<script>` … `</script>` |

## HTML：標籤

HTML 用「標籤」把內容包起來，有開始 `<名稱>` 和結束 `</名稱>`：

```html
<h1>冰水主機故障檢修模擬</h1>        ← h1 是大標題
<button id="pbOn">ON</button>       ← button 是按鈕，畫面上顯示 ON
```

`id="pbOn"` 是這個按鈕的**名字**，就像元件編號。JavaScript 靠這個名字找到按鈕。

## CSS：外觀規則

```css
.pb.green { background: #1f8f45; }
```

意思是：「class 同時有 `pb` 和 `green` 的東西，背景色是 `#1f8f45`（綠色）」。
`#1f8f45` 是顏色代碼。在 Google 搜尋「color picker」就能挑顏色、拿到代碼。

## JavaScript：動作

```js
$('#btnNfb').addEventListener('click', () => { setPower(!S.power); });
```

意思是：「找到名字叫 `btnNfb` 的按鈕（NFB），被點的時候，把送電狀態反過來（開變關、關變開）」。

## 註解：寫給人看的筆記

程式裡可以寫「註解」，瀏覽器會跳過，只給人看。我已經在 `index.html` 裡寫了很多中文註解：

| 語言 | 註解寫法 |
|---|---|
| HTML | `<!-- 這是註解 -->` |
| CSS | `/* 這是註解 */` |
| JavaScript | `// 這是單行註解` 或 `/* 多行註解 */` |

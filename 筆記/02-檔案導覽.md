# 02｜檔案導覽：index.html 每一段在做什麼

建議用 **VS Code**（免費，搜尋「Visual Studio Code 下載」）打開 `index.html`。它會把不同語法上不同顏色，比記事本好讀很多。
按 **Ctrl + F** 搜尋下面的【關鍵字】，就能直接跳到那一段。

## 專案資料夾

```
chiller-fault-trainer/
├── index.html      ← 遊戲本體（唯一需要的檔案）
├── README.md       ← GitHub 首頁顯示的說明
└── 筆記/            ← 你正在看的學習筆記
```

## index.html 由上到下

### 第一段：CSS（外觀）

| 搜尋 | 內容 |
|---|---|
| 【顏色設定】 | 全部顏色都在這裡，分淺色、深色兩組 |
| 三用電表 | 黑色電表、液晶字體 |
| 控制電路圖 | 導線粗細、元件線條顏色 |
| 控制盤面 | NFB、按鈕、指示燈的樣子 |

### 第二段：HTML（畫面結構）

| 搜尋 | 內容 |
|---|---|
| 【頁首】 | 標題、分數、出新題按鈕 |
| 【三用電表】 | 液晶、檔位按鈕、紅黑棒 |
| 【電路圖】 | 控制電路、主電路兩個空的框，電路圖由程式畫進去 |
| 【記事本】 | 玩家筆記區 |
| 【控制盤面】 | NFB1、NFB2、E-STOP、選擇開關、按鈕、泵浦、燈號 |
| 【導覽】 | 操作導覽的遮罩與說明卡 |
| 【現場設備】 | 冷卻水塔、水泵、壓縮機的圖 |
| 【說明文字】 | 右下角「練習步驟」「正常動作順序」，可以直接改文字 |

### 第三段：JavaScript（邏輯）

| 搜尋 | 內容 | 難度 |
|---|---|---|
| 【控制電路定義】 | 控制電路每個元件的名稱、位置、線號、電阻值 | ★★ |
| 【主電路定義】 | NFB1、MCM、MCS、MCD、壓縮機繞組、47R | ★★ |
| 【延時設定】 | 每個延時電驛的種類與（練習用）時間 | ★ |
| 接點邏輯 | 什麼情況下接點閉合 | ★★ |
| 電路求解 | 計算每一點幾伏特（三相用複數相量，可先跳過） | ★★★★ |
| 【物理模擬】 | 水溫、吐出溫度、高低壓、跳脫設定值 | ★★ |
| 【操作引導】 | 盤面上「下一步」的提示文字 | ★ |
| 【導覽步驟】 | 第一次打開時的操作導覽內容 | ★ |
| 【計分】 | 扣分規則 | ★ |
| 【出題】 | 隨機挑故障的規則 | ★★ |
| 【故障選項】 | 判定時的選項文字 | ★ |

## 遊戲每 0.1 秒在做的事

```
tick()
 ├─ stepLogic()    算電路：接點開關 → 每點電壓 → 哪些線圈吸合
 ├─ stepPhysics()  算現場：水流、水溫、壓力、會不會跳脫
 └─ render()       把結果畫到畫面上
```

就像真的機器：控制電路決定誰動作，機器動作後壓力溫度改變，壓力溫度又回頭影響開關（HP、LP、TC）。
